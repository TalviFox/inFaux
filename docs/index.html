Frequently Asked Questions

Everything You Need to Know

inFaux utilizes the Thermodynamic Observer pattern. It derives real-time ambient baseline temperatures from hardware diodes accessible via read-only user-mode IOCTLs (such as GPU and NVMe SMART controllers). It then reads live per-core clock frequencies and loads via native Windows Performance Data Helper (PDH) counters, calculating dynamic CMOS wattage and solving Newton's law of cooling using asymmetrical thermal low-pass filters.
Traditional monitoring utilities try to load a Ring-0 kernel driver to query hardware Model-Specific Registers (MSRs). Hypervisors intentionally strip and block these instructions, causing legacy monitors to crash or display blank values. Because inFaux is 100% user-mode, it runs cleanly on top of virtual performance counters, computing the exact thermal impact (ΔT) that the virtual workload contributes to the host CPU.
No. Anti-cheat engines routinely block or flag vulnerable Ring-0 drivers (like WinRing0 or older CPU-Z drivers) because they can be exploited for kernel code execution. inFaux runs strictly as a standard user process (asInvoker) and contains zero kernel drivers or injection DLLs, making it completely invisible and safe for gaming.
